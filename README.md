# Recruitment Funnel Efficiency Analyzer

## HR Analytics | SQL Server | Power BI | Excel

An end-to-end HR Analytics project designed to analyze the efficiency of an organization's recruitment process from application to joining.

The project uses synthetic/anonymized recruitment data and SQL Server to answer practical Talent Acquisition business questions. The results are transformed into an interactive Power BI dashboard for recruitment performance monitoring and decision-making.

---

## 📌 Project Overview

Recruitment teams generate large amounts of candidate data across different job roles, departments, locations, recruitment sources, recruiters, interview stages, offers, and joining outcomes.

However, simply tracking the number of applications does not explain whether the recruitment process is efficient.

This project analyzes the complete recruitment funnel:

Application → Screening → Assessment → Interview → Final Interview → Offer → Acceptance → Joining

The objective is to identify:

- Where candidates are dropping out
- Which recruitment sources generate successful hires
- Which departments and roles have higher hiring demand
- Which recruiters handle the highest workload
- How long the recruitment process takes
- How much the organization spends on recruitment
- Where offer acceptance or joining losses occur
- Why candidates are rejected or withdraw
- How salary expectations compare with offers
- How candidate experience varies
- How recruitment performance changes over time

# 🎯 Business Problem

The Talent Acquisition team needs a data-driven view of recruitment performance.

Management wants answers to questions such as:

1. How many applications are being received?
2. How many candidates progress through each recruitment stage?
3. Where is the largest funnel drop-off?
4. Which recruitment sources generate the most applications?
5. Which sources generate the most joiners?
6. Which sources have better application-to-hire conversion?
7. Which departments hire the most candidates?
8. Which job roles take the longest to fill?
9. Which recruiters handle the highest workload?
10. What is the average time-to-hire?
11. What is the cost-per-hire?
12. Why are candidates rejected?
13. Why do candidates withdraw?
14. What percentage of offers are accepted?
15. How many accepted candidates actually join?
16. Is there a gap between expected and offered salary?
17. How do candidates rate their recruitment experience?
18. How does hiring activity change month by month?

# 🎯 Project Objectives

The main objectives are:

- Analyze the complete recruitment funnel.
- Calculate recruitment stage conversion rates.
- Identify candidate drop-off points.
- Analyze recruitment source effectiveness.
- Measure recruiter workload and hiring output.
- Analyze department, job role, job level, and location performance.
- Calculate Time-to-Hire and Time-to-Fill.
- Analyze offer acceptance and joining conversion.
- Analyze rejection and withdrawal reasons.
- Calculate recruitment cost and Cost-per-Hire.
- Analyze offered salary versus expected salary.
- Analyze candidate experience ratings.
- Create an interactive Power BI dashboard.
- Generate actionable HR insights.

Assume a growing organization is hiring employees across multiple:

- Departments
- Job roles
- Job levels
- Locations
- Recruitment sources

Candidates enter the recruitment process through sources such as:

- LinkedIn
- Naukri
- Employee Referral
- Company Career Site
- Recruitment Agencies

- Campus Hiring
